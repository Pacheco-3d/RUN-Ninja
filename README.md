# RUN NINJA — NINJA RUSH V3

Endless runner 3D original com ninja e ciclo climático.

## Jogar
Abra [index.html](index.html) no navegador. O protótipo web roda offline e não é uma compilação WebGL do Unity.

## Controle
Setas ou A/D para trocar faixa, W/Espaço para saltar, S para deslizar, E para usar FOCO, P para pausa. No celular, use gestos de deslizar. T no modo treino muda a etapa do clima.

## Clima
Ciclo de 180 segundos: noite, amanhecer, dia, entardecer, noite e chuva. Molhamento torna o jogo lento; poças causam derrapagem.

## Projeto Unity
Existe também o projeto Unity 6 organizado no pacote ZIP entregue no ChatGPT. O personagem Unity é procedural e articulado por código. A versão navegador é uma implementação HTML/JS independente. A compilação Unity não foi testada neste ambiente.

## Referências
Arte conceitual e poses são materiais de referência, não modelos 3D jogáveis.
