# Clima dinâmico

Ciclo de 180 segundos: 0–12 noite, 12–29 amanhecer, 29–65 dia, 65–86 entardecer, 86–105 noite, 105–120 chuva chegando, 120–158 chuva forte, 158–180 chuva parando.

Durante a chuva: aceleração e resposta ao controle diminuem, o salto perde impulso e o ninja escorrega nas poças. Para testar etapas de clima use T no modo treino.

O código que implementa isso no navegador está em `web/assets/js/game.js`. O projeto Unity equivalente está no ZIP completo entregue via ChatGPT.
